## Installing

1. Grab the jar for your Minecraft version from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/samp-coasters).
2. Put it in your `mods` folder along with:
   - [Fabric API](https://www.curseforge.com/minecraft/mc-mods/fabric-api)
   - [Create Fly](https://www.curseforge.com/minecraft/mc-mods/create-fly) 6.0.9
3. Playing on a server? It needs to be on the server and on every player's client.
